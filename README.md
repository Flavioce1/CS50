## How to Run

C programs use the [CS50 library](https://cs50.readthedocs.io/libraries/cs50/c/):

```bash
cd "Week 01/credit"
make credit
./credit
```

Python programs (Week 6+):

```bash
cd "Week 06/dna"
python dna.py databases/large.csv sequences/5.txt
```

Flask apps (Week 9):

```bash
cd "Week 09/finance"
pip install -r requirements.txt
flask run
```
