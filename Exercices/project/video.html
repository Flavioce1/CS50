The idea

I never know if my week was good or bad globally.

Writing in a notebook is too long.

So I made a small website to save my mood every day.

What it does

  • Choose Good, Meh or Bad
  • Add a small note
  • See the count of each mood
  • See the list of all the days

Tools used

  • Python
  • Flask
  • SQLite
  • HTML and CSS
